# raytodo & rayteam 利用ガイド

[インストールと基本操作](../README.md)

## raytodo

### 状態・優先度

起動時は「すべて」を表示します。⌘Pで `todo` / `inprogress` / `pend` / `done` に絞り込めます。

- **⌘← / ⌘→**：状態を上記の順で変更。端では止まります。
- **⌘K → 状態を変更**：状態を直接選択。
- **Enter（一覧）**：`done` に変更。`done` なら `todo` に戻します。
- **⇧← / ⇧→**：優先度（triage）を `low ↔ mid ↔ high` で変更。端では止まります。

優先度は状態と独立しています。未指定の優先度は `mid` です。

### メモ・検索・並べ替え

新規タスクは末尾に追加します。作成・編集画面では、タスク名でEnterを押すとメモへ移動します。メモは複数行を入力できます。

検索はタスク名とメモ全文の部分一致です。一覧には、メモの最初の空でない行を表示します。コードブロック内のチェックリストは一覧に出しません。

⇧↑ / ⇧↓は、表示中の前後のTODOとメモを入れ替えます。移動後も同じTODOを選択します。同じ階層に連続するTODO内で使ってください。見出し・通常の文章をまたぐ移動や、親子関係を崩す移動は行いません。

### 保存形式

メモは、タスクより2スペース深い引用行で保存します。外部エディタでも同じ形式を使えます。

```markdown
- [ ] 打ち合わせ
  > 相談したい内容
  >
  > 補足メモ
```

状態はチェックボックス、優先度はタイトル末尾のコメントで保存します。

| 記号          | 状態       |
| ------------- | ---------- |
| `[ ]`         | todo       |
| `[/]`         | inprogress |
| `[-]`         | pend       |
| `[x]` / `[X]` | done       |

```markdown
- [/] 打ち合わせ <!-- triage:high -->
  > 相談したい内容
- [-] 返信待ち <!-- triage:low -->
```

### 削除

タスクを削除すると、そのメモも削除します。メモ以外の文章や子タスクは残します。

**⌘K → Doneのタスクを一括削除** は、検索・状態の絞り込みに関係なく全Doneタスクとそのメモを削除します。実行前に件数を確認します。未完了の子タスク、通常の文章、コードブロックは残します。Doneがない場合は表示しません。

## rayteam

| 期間   | 用途           |
| ------ | -------------- |
| Week   | 今週やること   |
| Month  | 今月やること   |
| Year   | 今年やること   |
| Future | いつかやること |

⌘Pで期間を選びます。「すべての期間」では4つをまとめて表示します。日付が変わってもタスクは自動で移動・削除されません。

⌘Nでタスク名・期間・メモを入力し、⌘Enterで保存します。追加時は表示中の期間を使い、「すべての期間」ならFutureになります。保存後も一覧の期間と検索文字列を維持します。

作成・編集画面では、タスク名でEnterを押すとメモへ移動します。⇧← / ⇧→で `Week ↔ Month ↔ Year ↔ Future` を選びます。端では止まります。一覧の **⌘K → 期間を移動** でも変更できます。

検索対象はタスク名とメモ全文です。完了タスクは各期間の末尾に残り、Enterで未完了に戻せます。

⇧↑ / ⇧↓は、表示中の前後のタスクとメモを入れ替えます。同じ期間の未完了同士、または完了同士が対象です。検索対象外のタスクは元の位置に残ります。端では止まり、移動後も同じタスクを選択します。並び順は再起動後も維持します。

## 保存・再読み込み

保存先はraytodoが `~/.raytodo/todo.md`、rayteamが `~/.rayteam/plans.json` です。保存前の内容を、各ファイルの `.raycast.bak` に1世代残します。

読み込み失敗や外部変更を検出した場合は、保存データを上書きしません。競合したら編集フォームから一覧へ戻り、⌘Rで再読み込みして開き直してください。外部エディタとはロックを共有しないため、同時保存は避けてください。

異常終了後に `.raycast.lock` が残った場合は、実行中の保存がないことを確認してから、そのロックファイルだけを削除してください。

Ctrl+Shift+Sでのコマンド切り替えは、一覧が空のときや読み込みに失敗したときも使えます。

## 初期化・再登録

`--ignore-scripts` 付きでインストールした場合も、初回起動時に不足する保存ファイルを作成します。手動で作成する場合は、リポジトリのルートでどちらかを実行します。

```sh
npm run postinstall --workspace=raytodo
# または
pnpm --filter raytodo run postinstall
```

拡張IDとディレクトリ名は `raytodo`、コマンドIDは `raytodo` / `rayteam` です。以前の拡張登録が残る場合は、新しいコマンドでデータを確認してから以前の登録を削除してください。起動用ホットキーは新しいコマンドへ設定し直してください。

## テスト

リポジトリのルートで `npm run test --workspace=raytodo` または `pnpm --filter raytodo test` を実行します。

保存先の作成・タスク操作・バックアップ・競合時の保護を一時ディレクトリで確認します。切り替えテストはRaycast APIの呼び出しを検証し、実際の画面操作は行いません。個人の保存データは変更しません。
