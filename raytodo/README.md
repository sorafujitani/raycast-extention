# raytodo & rayteam for Raycast

Raycastで `raytodo` を検索すると、その日に取り組むタスクを管理できます。`rayteam` は期間別の計画を管理します。一覧画面で **Ctrl+Shift+T** を押すと、互いに切り替わります。タスクが空のときや読み込みに失敗したときも切り替えられます。

保存先は `raytodo` が `~/.raytodo/todo.md`、`rayteam` が `~/.rayteam/plans.json` です。インストール時に作成し、初回起動時にも不足するファイルを作成します。再インストールしても既存ファイルは上書きしません。

## raytodo

| 操作                           | キー                        |
| ------------------------------ | --------------------------- |
| 追加                           | ⌘N                          |
| TODOを上・下へ移動             | ⇧↑ / ⇧↓                     |
| triageを下げる・上げる         | ⇧← / ⇧→                     |
| statusを前後に変更             | ⌘← / ⌘→                     |
| statusを選択                   | ⌘K → 状態を変更             |
| 表示するstatusを切替           | ⌘P                          |
| 完了・未完了の切替             | タスクを選んでEnter         |
| 編集                           | ⌘E                          |
| タスク名からメモへ移動         | Enter                       |
| 作成・編集を保存               | ⌘Enter                      |
| 削除（確認あり）               | Ctrl+X                      |
| Doneを一括削除（確認あり）     | ⌘K → Doneのタスクを一括削除 |
| 外部で編集した内容を再読み込み | ⌘R                          |
| ファイルを開く                 | ⌘O                          |

起動時は「すべて」を表示します。⌘Pで右上のstatus選択を開き、`todo` / `inprogress` / `pend` / `done` で絞り込めます。

⌘←/⌘→で `todo ↔ inprogress ↔ pend ↔ done` を変更します。端では止まり、循環しません。⌘Kの「状態を変更」から直接選ぶこともできます。Enterは現在の状態から `done` にし、`done` なら `todo` に戻します。

triageはstatusとは独立した優先度です。⇧←/⇧→で `low ↔ mid ↔ high` を変更します。端では止まり、循環しません。既存・新規タスクのtriage未指定時は `mid` です。

⇧↑/⇧↓は、現在表示されている前後のTODOとメモごと入れ替えます。移動後も同じTODOを選択します。見出し・通常の文章をまたぐ移動や、親子関係を崩す移動は行いません。同じ階層に連続するTODO内で使ってください。

新規タスクは末尾に追加します。作成・編集画面の「メモ」には複数行を入力できます。一覧にはメモの最初の空でない行を表示し、検索はタスク名とメモ全文の部分一致です。

メモはタスク直下の、タスクより2スペース深い引用行として保存します。外部エディタでも同じ形式で編集できます。

```markdown
- [ ] 打ち合わせ
  > 相談したい内容
  >
  > 補足メモ
```

statusはチェックボックスで保存します。`[ ]` が `todo`、`[/]` が `inprogress`、`[-]` が `pend`、`[x]` が `done` です。既存の `[X]` も `done` として読み込めます。triageはタイトル末尾のコメントで保存します。

```markdown
- [/] 打ち合わせ <!-- triage:high -->
  > 相談したい内容
- [-] 返信待ち <!-- triage:low -->
```

タスクを削除すると、そのメモも削除します。メモ以外の文章や子タスクは残します。コードブロック内のチェックリストは一覧に出しません。

「Doneのタスクを一括削除」は、検索・statusの絞り込みに関係なく全Doneタスクとそのメモを削除します。実行前に件数を確認します。未完了の子タスクや通常の文章、コードブロックは残します。Doneがない場合、この操作は表示しません。

保存前の内容は `todo.md.raycast.bak` に1世代保存します。外部変更を検出した場合は上書きせず、再読み込みを求めます。編集フォームで競合した場合は一覧に戻って開き直してください。外部エディタとはロックを共有しないため、同時保存は避けてください。

異常終了後に `.raycast.lock` が残った場合は、実行中の保存がないことを確認してから、そのロックファイルだけを削除してください。

## rayteam

Raycastで `rayteam` を起動すると、今後やることを期間別に管理できます。

- **Week**：今週やること
- **Month**：今月やること
- **Year**：今年やること
- **Future**：いつかやること

⌘Pで期間を切り替えます。「すべての期間」では4つの期間をまとめて表示します。日付が変わってもタスクは自動で移動・削除されません。

⌘Nでタスク名・期間・メモを入力し、⌘Enterで保存します。追加・編集画面では、タスク名でEnterを押すとメモへ移動します。⇧← / ⇧→で `Week ↔ Month ↔ Year ↔ Future` を切り替えます。端では止まり、循環しません。

追加時の期間は表示中の期間です。「すべての期間」から追加する場合はFutureになります。保存後は、作成画面を開く前の表示期間と検索文字列を維持します。

- **Enter（一覧）**：完了・未完了を切り替える
- **⇧↑ / ⇧↓（一覧）**：タスクを上・下へ移動する
- **⌘E**：タスクを編集する
- **⌘K → 期間を移動**：別の期間へ移す
- **Ctrl+X**：確認して削除する
- **⌘R**：保存データを再読み込みする
- **⌘O**：保存先のJSONファイルを開く
- **Ctrl+Shift+T**：raytodoへ切り替える

検索対象はタスク名とメモ全文です。完了したタスクは各期間の末尾に残り、未完了に戻せます。

⇧↑ / ⇧↓は、表示中の前後のタスクとメモごと入れ替えます。同じ期間の未完了同士、または完了同士で並べ替えられます。検索対象外のタスクは元の位置に残ります。端では止まり、移動後も同じタスクを選択します。並び順は保存され、再起動後も維持します。

データは `~/.rayteam/plans.json` に保存します。拡張をアンインストールしてもファイルは残ります。保存前の内容は `plans.json.raycast.bak` に1世代保存します。読み込みに失敗した場合や外部変更を検出した場合は上書きしません。競合したときは編集フォームから一覧に戻り、⌘Rで再読み込みしてください。外部エディタとの同時保存は避けてください。

## インストール・登録

Node.js 22.22.2以上とRaycastが必要です。リポジトリのルートで、npmかpnpm 11.18.0のどちらかを使います。

```sh
cd "$(ghq root)/github.com/sorafujitani/raycast-extention"
pnpm --filter raytodo install --frozen-lockfile
pnpm --filter raytodo typecheck
pnpm --filter raytodo build
pnpm --filter raytodo dev
```

npmを使う場合は次を実行します。

```sh
npm install --workspace=raytodo --include-workspace-root
npm run typecheck --workspace=raytodo
npm run build --workspace=raytodo
npm run dev --workspace=raytodo
```

どちらもraytodo・rayteamを含む拡張と共通開発ツールをインストールします。他の自作拡張は対象外です。`~/.raytodo/todo.md` と `~/.rayteam/plans.json` を作成し、既存ファイルは上書きしません。

`npm run dev --workspace=raytodo` または `pnpm --filter raytodo dev` でローカル登録できます。ビルド完了後はCtrl+Cで停止しても利用できます。拡張IDとディレクトリ名は `raytodo`、コマンドIDは `raytodo` / `rayteam` です。

以前の拡張登録が残っている場合は、新しいコマンドで保存データを確認してからRaycast設定で以前の登録を削除してください。起動用ホットキーは新しいコマンドへ設定し直してください。一覧内の切り替えはCtrl+Shift+Tのままです。

インストール時のスクリプトを無効にしている場合も、各コマンドの初回起動で保存先を作成します。手動作成には `npm run postinstall --workspace=raytodo` または `pnpm --filter raytodo run postinstall` を使います。

テストは `npm run test --workspace=raytodo` または `pnpm --filter raytodo test` で実行できます。

テストは一時ディレクトリで保存先の作成・タスク操作・バックアップ・競合時の保護を確認します。切り替えテストではRaycast APIの呼び出しを確認し、実際の画面操作は行いません。個人の保存データは変更しません。
