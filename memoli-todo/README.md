# Memoli Todo for Raycast

Raycastで `Memoli Todo` を検索して起動します。`~/.memoli/memo/todo.md` のチェックリストを直接操作します。Memoliの `tasks.json` とは連動しません。

| 操作 | キー |
| --- | --- |
| 追加 | ⌘N |
| 完了・未完了の切替 | タスクを選んでEnter |
| 編集 | ⌘E |
| タスク名からメモへ移動 | Enter |
| 作成・編集を保存 | ⌘Enter |
| 削除（確認あり） | Ctrl+X |
| 外部で編集した内容を再読み込み | ⌘R |
| ファイルを開く | ⌘O |

起動時は「すべて」を表示します。右上で未完了・完了・すべてを切り替えられます。新規タスクは末尾に追加します。作成・編集画面の「メモ」には複数行を入力できます。一覧にはメモの最初の空でない行を表示し、検索はメモ全文も対象にします。

メモはタスク直下の、タスクより2スペース深い引用行として保存します。外部エディタでも同じ形式で編集できます。

```markdown
- [ ] 打ち合わせ
  > 相談したい内容
  >
  > 補足メモ
```

タスクを削除すると、そのメモも削除します。メモ以外の文章や子タスクは残します。コードブロック内のチェックリストは一覧に出しません。

保存前の内容は `todo.md.raycast.bak` に1世代保存します。外部変更を検出した場合は上書きせず、再読み込みを求めます。編集フォームで競合した場合は一覧に戻って開き直してください。外部エディタとはロックを共有しないため、同時保存は避けてください。

異常終了後に `.raycast.lock` が残った場合は、実行中の保存がないことを確認してから、そのロックファイルだけを削除してください。

## 開発・再登録

Node.js 22.18以上とRaycastが必要です。

```sh
cd "$(ghq root)/github.com/sorafujitani/raycast-extention/memoli-todo"
npm ci
npm test
npm run typecheck
npm run build
npm run dev
```

`npm run dev` でローカル登録できます。ビルド完了後はCtrl+Cで停止しても利用できます。Storeへの公開やGitリポジトリ作成は不要です。

テストは一時ファイルで追加・編集・完了切替・削除・バックアップ・競合時の保護を確認し、実際の `todo.md` は変更しません。
